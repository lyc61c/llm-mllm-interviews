## 岗位路线

| 岗位 | 主线 | 补充 |
|---|---|---|
| LLM 算法 / 后训练 | TFM → PRE → FT → ALN → EVA | INF / DST / COD / PRJ |
| MLLM 算法 | TFM → VLM → OMM → FT → ALN → EVA | DST / COD / PRJ |
| AI Infra / 推理 | TFM → INF → DST → COD → SYS | PRE / FT / EVA |
| RAG / Agent 应用 | TFM 基础 → RAG → AGT → EVA → SYS | FT / COD / PRJ |

所有方向都需要个人项目的指标、失败案例和可核验贡献。不要用模拟系统设计冒充自己的上线经验。

## 四周计划

| 周 | 目标 | 每天的可交付物 |
|---|---|---|
| 1 | TFM/PRE/FT 的基础与推导 | 5–8 题口述 + 1 条公式 + 一个边界例子 |
| 2 | 岗位专项：ALN 或 VLM/OMM 或 INF/DST | 5–8 题 + 1 张模块/数据流草图 + 一条取舍 |
| 3 | RAG/AGT/EVA/SYS 与代码 | 一个手撕实现 + 测试 + 一个归因实验设计 |
| 4 | PRJ 与模拟面试 | 一次 45–60 分钟模拟 + 错题记录与复测 |

时间有限时缩减每日题量，保持“回答→追问→纠错→复测”的闭环，而非通读所有答案后以为自己会了。

## 一小时模拟面试

1. 5 分钟：两分钟项目介绍，三分钟核对个人贡献与指标口径。
2. 15 分钟：2 道 L1 + 2 道 L2，至少推导一条公式。
3. 15 分钟：一道手撕题，先说 shape/复杂度，再写代码与边界测试。
4. 15 分钟：一道系统或多模态场景题，先确认约束，再设计验证。
5. 10 分钟：追问、失败案例和复盘。

## 评分与错题

每题 0–4 分：0 无法解释；1 只会术语；2 能说原理；3 能给公式/实现/边界；4 能独立验证并讨论取舍。这个评分用于个人复习，不是雇主评分标准。

记录“题号、错误原因、正确依据、复测日期、仍不确定的条件”。数学、工程与来源错误分别处理。例如：

```text
COD-003 | 缓存 mask 没加 past_len | 用绝对位置比较，验证 decode=prefill | 下次复测
ALN-*   | 把 DPO 说成完全没有奖励含义 | 区分显式 reward model 与隐式偏好目标
DST-*   | 只算 16P 便说是总显存 | 补激活、通信、工作区与分片峰值
```

不要背“某方法一定优于另一方法”。有用的答法是解释目标、假设、适用数据、预算与验证方案。
