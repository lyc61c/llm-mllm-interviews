## 强化学习基础

<a id="aln-021"></a>
### ALN-021 · 强化学习怎样建模为 MDP？V、Q、Bellman 与 LLM 生成怎样对应？

**L1**

#### 答案

强化学习把连续决策看成“观察状态、选择动作、环境变化、获得奖励”的过程，目标是让整段交互的期望回报更高。MDP 是马尔可夫决策过程，要求状态包含预测下一步所需的信息；只有转移是马尔可夫过程，加奖励成为奖励过程，再加入动作和策略才是决策过程。

公式中 $`G_t`$ 是从时刻 $`t`$ 起的折扣回报，$`r`$ 是奖励，$`\gamma`$ 控制未来折扣。$`V^\pi(s)`$ 表示按策略 $`\pi`$ 从状态继续走的平均回报，$`Q^\pi(s,a)`$ 表示先选动作 $`a`$，再按策略继续的平均回报。Bellman 方程把这些价值拆成当前奖励与下一状态价值，例如“现在得到 1 分，后续预计 4 分，折扣 0.9”，当前估值就是 4.6。

LLM 可把问题加已生成前缀当状态，把下一 token 当动作，EOS 或任务规则定义终止。Agent 还要包括工具观察、记忆等，否则可能遗漏影响未来的信息；观察不完整时，可以使用历史或信念状态描述部分可观测问题。固定策略后，MDP 会诱导一个奖励过程。

价值不是动作概率，也不与策略一一对应；多个动作可能同样好。强化学习可以依赖答案标签、人工偏好或模拟器，不是“无需标签”的定义；深度学习则是表示和优化函数的一种手段，两者并不对立。

```math
\begin{aligned}G_t&=\sum_{k=0}^{T-t-1}\gamma^k r_{t+k+1}\\ V^\pi(s)&=\mathbb E_{a\sim\pi,\,s^\prime,r}[r+\gamma V^\pi(s^\prime)]\\ Q^\pi(s,a)&=\mathbb E_{s^\prime,r}[r+\gamma\mathbb E_{a^\prime\sim\pi}Q^\pi(s^\prime,a^\prime)]\end{aligned}
```

#### 易错点

- 强化学习可以使用标签或专家反馈，也不要求每个状态都能重复到达。

- LLM Agent 的外部网页状态不可见时，怎样构造状态？

<a id="aln-022"></a>
### ALN-022 · 动态规划、Monte Carlo、TD 与 n-step return 有什么区别？

**L2**

#### 答案

动态规划、Monte Carlo 和时间差分 TD，主要区别是价值目标来自已知模型、完整真实轨迹，还是“部分奖励加价值预测”。动态规划假设知道环境转移和奖励，能算期望并反复评价、改进策略；Monte Carlo 用采样到的整段回报，通常要等任务结束。

TD 不必等结束，例如拿到一步奖励后，用 $`r_{t+1}+\gamma V(s_{t+1})`$ 更新当前价值。公式中的 $`\alpha`$ 是学习率，gamma 是折扣；用已有估值补后续叫 bootstrap。假设一步奖励为 1，下一状态估值为 4，gamma 为 0.9，目标就是 4.6。它适合在线更新，但下一状态价值不准会影响目标。

n-step return 先用前 $`n`$ 步的真实奖励，再用第 $`n`$ 步状态价值补余下部分。步数增加通常减少 bootstrap 依赖，也可能累计更多随机性、提高方差，但不是所有偏差和方差都严格单调变化。Monte Carlo 在合适条件下给出价值的无偏回报样本，也不意味着最终学习算法永远无偏。GAE 可以理解为不同跨度优势估计的加权组合。

真实终止后未来价值为零，时间限制截断却未必表示任务自然结束，要按语义决定是否 bootstrap。使用已知或学习到的环境模型规划属于 model-based，直接从经验学价值或策略属于 model-free；前者会有模型误差，后者也不天然更容易泛化。

```math
\begin{aligned}V(s_t)&\leftarrow V(s_t)+\alpha\big[r_{t+1}+\gamma V(s_{t+1})-V(s_t)\big]\\ G_t^{(n)}&=\sum_{k=0}^{n-1}\gamma^k r_{t+k+1}+\gamma^n V(s_{t+n})\end{aligned}
```

#### 易错点

- n-step 步数增加不意味着真实价值更大，也不保证偏差与方差严格单调变化。

#### 追问

- 为什么截断成 max_tokens 的回答不应无条件当作真实终止？

<a id="aln-023"></a>
### ALN-023 · 怎样推导策略梯度与 REINFORCE，baseline 为什么能降方差？

**L2**

#### 答案

策略梯度通过提高高回报动作的概率、降低低回报动作的概率来改进策略，REINFORCE 是直接用采样回报做这种更新的方法。它不需要让梯度穿过离散 token 或不可微环境，而是对“生成这条轨迹的概率”求导。

把轨迹概率写成初始状态、环境转移和各步策略概率的乘积，对期望回报求导，用 $`\nabla p=p\nabla\log p`$ 就能得到回报乘 log-prob 梯度。环境不依赖策略参数时，只有策略动作概率参与这一项；再利用当前动作不能改变过去奖励，把整段回报换成该动作之后的 reward-to-go。公式中 $`G_t`$ 是从 $`t`$ 开始的折扣回报，若目标从时刻零折扣，还需要外面的 $`\gamma^t`$；有限回答常取 gamma 为 1。

Baseline 是不依赖当前动作的基线，例如状态价值 $`V(s)`$。在固定状态上，$`b(s)\sum_a\pi(a\mid s)\nabla\log\pi(a\mid s)=b(s)\nabla1=0`$，所以不改变期望梯度，却能减少随机波动。例如同题平均能拿 0.8 分，0.9 分回答用 0.1 的优势更新，比直接用 0.9 更突出相对差异。

实现最小化负的 log-prob 与回报或优势乘积，这些权重通常停止梯度。动作相关基线没有上述直接保证，随意使用会引入偏差。每轮采样分布会改变，因此代理 loss 不能像固定 SFT 损失一样跨轮解释，仍应看独立任务奖励和泛化。

```math
\begin{aligned}\nabla_\theta J&=\mathbb E_\tau\left[\sum_t \gamma^t\nabla_\theta\log\pi_\theta(a_t\mid s_t)\big(G_t-b(s_t)\big)\right]\\ \mathbb E_{a\sim\pi}[b(s)\nabla_\theta\log\pi(a\mid s)]&=b(s)\nabla_\theta\sum_a\pi(a\mid s)=0\end{aligned}
```

#### 易错点

- 状态基线的无偏证明依赖它不直接依赖当前动作，任意动作相关基线没有这个保证。

#### 追问

- 为什么提高好回答的概率不等于只训练这些回答的 SFT？

<a id="aln-024"></a>
### ALN-024 · Actor-Critic、A2C 与 A3C 怎样工作，Critic 是奖励模型吗？

**L2**

#### 答案

Actor-Critic 让 Actor 负责选动作，Critic 负责估计未来回报，帮助 Actor 判断这次动作比平时好多少。Critic 不是评价答案好坏的奖励模型，而是估计“在当前策略下，从这个状态继续大概还能拿多少奖励”。

Actor 常用负 log-prob 乘优势训练，Critic 则回归实际或估计的 return target。公式中 $`\mathrm{sg}`$ 表示停止梯度，$`\hat A_t`$ 是优势估计，$`\hat G_t`$ 是回报目标。例如一个前缀预测后续能拿 0.6，实际回报为 1，就给 Actor 提供正向信号，并把 Critic 往 1 修正。共享骨干时，两类损失会影响同一参数，要注意权重和梯度冲突。

A3C 用多个工作进程与独立环境交互，局部参数从共享模型同步，再异步提交更新；这有助于打散轨迹相关性，但参数滞后仍存在。A2C 把多个环境的 rollout 同步聚合再更新，更便于批量计算。它们通常作为 on-policy 方法讨论，但异步不自动等于无滞后，是否 off-policy 要看行为策略与学习目标。

RLHF 中 RM 产生质量奖励，Critic 预测包含该奖励及 KL 惩罚后的未来回报，两者不能互换。理论优势是 $`Q-V`$，一步 TD 残差只是估计，不是每个样本都精确等于真优势。Critic 也不一定需要独立的 Q 网络。

```math
\mathcal L_{\mathrm{actor}}=-\mathbb E[\log\pi_\theta(a_t\mid s_t)\mathrm{sg}(\hat A_t)],\qquad \mathcal L_{\mathrm{critic}}=\mathbb E[(V_\phi(s_t)-\mathrm{sg}(\hat G_t))^2]
```

#### 易错点

- Critic 预测策略回报，不是奖励判别器，也不必须独立学习 Q 网络。

#### 追问

- Actor 与 Critic 共用 Transformer 时，应怎样检查梯度冲突？

<a id="aln-034"></a>
### ALN-034 · on-policy、off-policy、importance sampling、TRPO 与 PPO 怎样联系？

**L2**

#### 答案

On-policy 主要用当前交互策略的数据学习，off-policy 可以用不同的行为策略数据学习目标策略；重要性采样用于补偿分布差异，TRPO 和 PPO 则限制策略更新幅度。是否用了回放、多线程或概率比，不能单独决定方法属于哪一类。

公式把目标分布 $`p`$ 下的期望，改写成行为分布 $`q`$ 下用 $`p/q`$ 加权的期望。条件是目标有概率的事件，行为也必须覆盖，否则无法从没有采到的区域恢复信息。例如行为对某动作概率 0.1、目标概率 0.2，这个动作的样本权重为 2。整条轨迹比率是各步比率的乘积，长轨迹可能极大或极小，方差因此很高。

TRPO 用新旧 KL 约束求近似信赖域更新，常涉及二阶近似和线搜索。PPO-clip 用一阶优化的截断代理目标，PPO-penalty 使用 KL 惩罚，工程上更容易实现，但 clip 不保证严格 KL 上界。截断、自归一化和局部代理目标可控制方差，却通常带来偏差或改变目标，不能说任意老样本都被无偏校正了。

PPO 通常每轮用当前策略收集，再有限复用这批 rollout，更新后重新采样。新旧策略限制针对局部更新；RLHF 相对固定参考模型的 KL 则是行为锚点，两者又要区分。样本越旧、偏差越大，越应监测比率和 KL，而不是把 PPO 当任意离线回放算法。

```math
\mathbb E_{z\sim p}[f(z)]=\mathbb E_{z\sim q}\left[\frac{p(z)}{q(z)}f(z)\right],\qquad p(z)\gt 0\Rightarrow q(z)\gt 0
```

#### 易错点

- PPO 通常使用有限复用的新鲜 rollout，存在概率比不等于能无偏使用任意历史回放。

#### 追问

- 为什么重要性比例在长回答上常比短回答更不稳定？

<a id="aln-035"></a>
### ALN-035 · Q-learning 与 SARSA 的更新、探索策略和适用边界有什么区别？

**L2**

#### 答案

Q-learning 和 SARSA 都用一步奖励加下一状态价值来更新动作价值，区别是下一步按最佳动作估值，还是按实际探索策略选择的动作估值。Q 值是期望回报，不是动作概率。

Q-learning 的目标是 $`r+\gamma\max_a Q(s',a)`$，行为可以用 epsilon-greedy，即大多数时候选当前最好动作、少数时候随机探索，所以行为与学习目标不同，属于 off-policy。SARSA 的目标是 $`r+\gamma Q(s',a')`$，其中 $`a'`$ 按当前行为策略选择，学习的是包含探索行为的策略，属于 on-policy。公式中的 alpha 是步长，gamma 是折扣。

例如下一状态有两个动作估值 10 和 2，探索恰好选了第二个，忽略当前奖励时 Q-learning 使用折扣后的 10，SARSA 使用折扣后的 2。因此在会因探索而掉入危险区域的任务里，SARSA 可能更重视探索风险，但并不是总比 Q-learning 更好。选出 $`a'`$ 后就可以更新当前转移，不必等下一动作实际执行完成。

表格型收敛还要求充分访问和合适步长等条件，神经网络下不能直接照搬。连续动作的最大值搜索很难，常借助 Actor；LLM 虽是离散大词表，也面临长程状态、信用分配和计算成本，不能只把 Q 表换成 Transformer 就假定适用。

```math
\begin{aligned}Q_{\mathrm{Q\text{-}learn}}(s_t,a_t)&\leftarrow Q(s_t,a_t)+\alpha[r_{t+1}+\gamma\max_aQ(s_{t+1},a)-Q(s_t,a_t)]\\ Q_{\mathrm{SARSA}}(s_t,a_t)&\leftarrow Q(s_t,a_t)+\alpha[r_{t+1}+\gamma Q(s_{t+1},a_{t+1})-Q(s_t,a_t)]\end{aligned}
```

#### 易错点

- SARSA下一动作要按行为策略选择，但不必实际执行完下一动作后才更新当前transition。

#### 追问

- 若行为策略和target都贪心，两种一步更新还会有什么差别？

<a id="aln-036"></a>
### ALN-036 · DQN 的经验回放和目标网络做什么，Double DQN 与 Dueling DQN 分别改了什么？

**L2**

#### 答案

DQN 用神经网络预测每个离散动作的价值，经验回放减少连续样本相关性，目标网络让回归目标暂时稳定；Double DQN 改怎样构造目标，Dueling DQN 改网络怎样表示价值，二者可以组合。

回放把过去转移放进缓冲区并随机抽样，提高复用，但不保证样本完全独立。目标网络是在线网络的延迟副本，隔一段时间或缓慢更新，避免同一个网络一边预测一边立刻追逐自己移动的目标。目标太快可能仍振荡，太慢又可能滞后，这需要按任务判断。

普通 DQN 用目标网络既选最大动作又评价它，最大值会放大噪声。Double DQN 用在线网络选 $`\arg\max`$ 动作，再让目标网络评价这个动作，减少选择与估值误差的耦合。公式里 $`s'`$ 是下一状态，$`r`$ 是当前奖励，gamma 是折扣；两个网络不是两个 Actor。

Dueling 把 Q 分成状态价值 $`V(s)`$ 和动作优势 $`A(s,a)`$，再减掉动作优势均值，使表示更可辨识。例如多个动作都差不多时，网络可以先学到“这个状态总体很好”，再学动作差异。Dueling 不是对抗训练，Double 也不是网络分支结构变化。这些设计改善稳定性或估计，却不提供一般神经函数逼近下的收敛保证，DQN 本身也没有必须独立生成动作的 Actor。

```math
\begin{aligned}y_{\mathrm{DDQN}}&=r+\gamma Q_{\mathrm{target}}(s^\prime,\arg\max_aQ_{\mathrm{online}}(s^\prime,a))\\ Q(s,a)&=V(s)+A(s,a)-\frac1{|\mathcal A|}\sum_{a^\prime}A(s,a^\prime)\end{aligned}
```

#### 易错点

- Double 改目标估计，Dueling 改价值分解，前者不是双 Actor，后者不是对抗训练。

#### 追问

- 目标网络更新太频繁或太慢分别可能产生什么问题？

<a id="aln-037"></a>
### ALN-037 · DDPG、D4PG、TD3 与 SAC 怎样比较，能直接套到 LLM token 生成吗？

**L2**

#### 答案

DDPG、D4PG、TD3 和 SAC 主要面向连续动作控制，不能直接把其中的动作求导规则套到 LLM 离散 token。它们都结合策略与价值，但对探索、价值表示和误差控制的设计不同。

DDPG 用确定性 Actor 输出连续动作，Critic 估计 Q，并通过 Q 对动作的梯度更新 Actor，配合经验回放、目标网络和行为噪声。D4PG 在这个框架上增加分布式采样、回报分布表示、n-step 和优先回放等；distributed 是多个采样者，distributional 是预测回报分布，两者不是同一个词义。

TD3 用两个 Critic 的较小目标值减少过估计，延迟 Actor 更新，并给目标动作加平滑噪声。SAC 学随机策略，把期望回报和熵一起优化；公式中 $`\mathcal H`$ 是策略随机程度，alpha 控制其权重。例如机器人需要既获得高奖励，又避免过早只尝试单一动作，熵项可以鼓励探索，但并非越大越好。

LLM 的动作是词表中的离散选项，普通连续确定性梯度无法穿过 token 采样。可以研究离散 SAC 等变体，但要明确动作分布、价值计算及大词表成本，而不是换个网络名称就宣称算法等价。策略梯度也能处理离散动作，价值方法也能配探索策略，不能用“连续与确定”做过度简单分类。

```math
J_{\mathrm{SAC}}=\mathbb E\left[\sum_t\gamma^t\big(r_t+\alpha\mathcal H(\pi(\cdot\mid s_t))\big)\right]
```

#### 易错点

- “策略梯度只适用于连续动作、价值方法只适用于确定策略”都不是正确边界。

#### 追问

- 离散大词表上计算所有动作Q值与连续动作Actor求导有何成本差异？

<a id="aln-038"></a>
### ALN-038 · 稀疏奖励怎样改善，reward shaping、课程学习与 ICM 有什么风险？

**L2**

#### 答案

稀疏奖励只在少数成功事件给反馈，模型可能很久都收不到能指导学习的信号，可以从任务难度、示范、过程反馈和探索方式改善。奖励变密并不自动更好，额外分数必须与最终目标一致。

课程学习可以先让模型完成较短或较简单任务，再逐步增加难度；示范帮助它进入有成功机会的区域。势函数 shaping 用 $`\gamma\Phi(s_{t+1})-\Phi(s_t)`$ 增加奖励，$`\Phi`$ 是状态的势能，在匹配折扣和终止条件下，这些差值会望远镜式抵消，因此可保留最优策略。随意给“思考更长”或“调用更多工具”加分，没有同样保证。

ICM 用学习到的特征 $`\phi(s)`$ 表示状态，通过逆动力学训练特征，并把前向模型对下一特征的预测误差当内在奖励。公式中的 $`f`$ 预测下一特征，误差大表示当前行为带来难预测的变化。但难预测不等于有用，例如不断看随机画面或调用随机数工具，误差可以一直很高，这就是 noisy TV 一类风险。

Agent 应联合外部成功目标、资源限制和内在奖励权重验收。诊断时检查高内在奖励轨迹是否实际获取了有用信息，而不是制造新奇输出。更细的过程评分同样可能被利用，最终成功率和独立评测仍是必要依据。

```math
\begin{aligned}r_t^\prime&=r_t+\gamma\Phi(s_{t+1})-\Phi(s_t)\\ r_t^{\mathrm{intrinsic}}&\propto\left\|f(\phi(s_t),a_t)-\phi(s_{t+1})\right\|_2^2\end{aligned}
```

#### 易错点

- 更密集的奖励不保证原任务最优策略不变；好奇心也不保证探索有用信息。

#### 追问

- 如果Agent不断调用返回随机数的工具，怎样发现和修复奖励作弊？

<a id="aln-039"></a>
### ALN-039 · 行为克隆、DAgger、IRL 与 GAIL 有何区别，怎样对应 Agent 训练？

**L2**

#### 答案

行为克隆直接模仿专家动作，DAgger 在学生实际走到的状态上继续请专家纠正，IRL 从示范推断奖励，GAIL 则通过对抗信号让学生轨迹分布接近专家。它们使用专家数据的方式不同，也不能仅凭示范恢复唯一真实意图。

行为克隆的公式是专家状态动作上的负 log-prob，$`\mathcal D_E`$ 是示范集。例如 Agent 学会在专家看到某网页时调用哪个工具，但部署时一次小错误把它带到陌生页面，原示范未必教过怎样恢复。DAgger 让当前策略运行，收集它访问的状态，再请专家给该状态下的动作并聚合训练，改善这种分布偏移；成本是专家查询和可控环境。

IRL 寻找能解释专家行为的奖励，然后据此优化策略，但很多奖励都能解释相同示范，专家也未必最优。GAIL 用判别器区分专家与学生的状态动作占用分布，再用代理信号更新策略，目标是模仿这种分布，并不保证发现唯一真实奖励。对抗结构像 GAN，但样本来自环境交互轨迹。

Agent 训练应包含工具选择、参数、观察和错误恢复，而不只有最终答案。让专家重写最终答案，不等于纠正每个错误状态的动作。采集当前策略失误时也要保持任务允许的执行边界，不为探索无约束行动；最终比较真实成功率、泛化和查询成本。

```math
\mathcal L_{\mathrm{BC}}=-\mathbb E_{(s,a)\sim\mathcal D_E}[\log\pi_\theta(a\mid s)]
```

#### 易错点

- 模仿学习不能保证把专家全部行为精确复制，也不能据示范唯一识别人类真实意图。

#### 追问

- 让专家只重写Agent最终答案，为什么不等于在错误状态上做DAgger？

### ALN-001 · SFT、RLHF 与 DPO 分别解决什么问题？

**L1** · 字节跳动 / 阶跃星辰 / 美团 / 阿里巴巴

#### 答案

SFT 用好答案教模型怎样完成任务，RLHF 用人类偏好反馈选择更好的行为，DPO 则把偏好回答对直接变成训练损失。它们解决的是监督信号不同的问题，不能简单说 SFT 只学知识、强化学习只学推理。

SFT 通常让模型模仿有效助手回答，适合建立格式、任务接口和基本能力。做完 SFT 后，如果完整答案容易评分、优质轨迹却难大量写出，可以让当前模型生成候选，再用奖励优化。例如代码有测试可执行，不必人工写出每条正确推导，就能反馈最终是否成功。强化学习也覆盖模型实际生成的前缀，但奖励差或知识基础不足时，不能保证它补齐缺失能力。

经典 RLHF 先对同一问题收集偏好回答，训练奖励模型，再用 PPO 等更新策略。策略 Actor 和价值 Critic 通常训练，参考策略与奖励模型在这一阶段通常冻结；采样旧策略是当前一轮的快照，参考策略是长期行为锚点。四种逻辑角色不一定是四套独立同尺寸模型。规则验证也可以直接提供奖励，而不使用学习到的奖励模型。

DPO 使用同问题的优选与非优选回答，通过相对参考模型的概率变化学习偏好，省去独立奖励模型和在线 RL 循环。有优质示范先做 SFT，有可靠离线偏好可以比较 DPO，有可信奖励且值得探索才比较在线 RL。三者可以串联或混合，但不能为补齐流程强行增加阶段；最终要在一致预算下比较任务质量、泛化和成本。

#### 易错点

- SFT后RL是常见配方，不是所有任务和所有模型的必要条件。
- “好样本SFT、坏样本loss取负”不等价于完整策略分布上的RL，需另看负CE目标和信用分配。

#### 追问

- 同一bad case何时补SFT示范，何时补偏好对，何时采样做RL？
- 奖励只识别格式时，SFT后RL可能优化出什么错误行为？

<a id="aln-003"></a>
### ALN-003 · PPO 的概率比、clip 和 min 分别起什么作用？

**L2**

#### 答案

PPO 的概率比衡量当前策略把某个动作变得更可能了多少，clip 和 min 则让过大的有利更新不再继续获得目标收益，减少一批样本把策略推得太远。公式里的 $`\rho_t=\pi_\theta(a_t\mid s_t)/\pi_{\rm old}(a_t\mid s_t)`$ 是新旧策略比，$`A_t`$ 是该动作相对基线的优势，$`\epsilon`$ 决定裁剪区间。

假设旧策略对动作的概率是 0.2，新策略变成 0.3，比率就是 1.5。若优势为 2、$`\epsilon=0.2`$，原项是 3，裁剪项是 2.4，取 min 得到 2.4；继续增大概率也不会提升这个样本的目标。若优势为 -2，把比率降到 0.5 时，原项是 -1，裁剪项是 -1.6，min 选 -1.6，同样限制了过度降低坏动作概率带来的收益。

外面的 min 很关键：正优势主要截住上边界，负优势主要截住下边界，反方向的不利变化仍会被惩罚。只用裁剪后的比率，可能把需要纠正的不利区域也变成无梯度。训练通常最大化这个代理目标，代码若采用最小化损失，需要取负。

Clip 既不裁剪参数，也不保证所有概率比都在区间内，更不是严格的 KL 信赖域。因此复用同一批 rollout 时，还要看新旧策略 KL、裁剪比例、熵和价值损失，必要时提前停止这一轮更新。

```math
L^{\mathrm{clip}}=\mathbb{E}\left[\min\left(\rho_t A_t,\mathrm{clip}(\rho_t,1-\epsilon,1+\epsilon)A_t\right)\right]
```

#### 易错点

- Clip 减少过度更新的收益，却不保证概率比或 KL 严格留在边界内。

#### 追问

- 只保留裁剪项而去掉外面的 min，会在什么区域失去需要的纠正梯度？

<a id="aln-004"></a>
### ALN-004 · GAE 如何计算，λ 与 γ 如何影响优势估计？

**L2** · 字节跳动 / 小红书

#### 答案

GAE 用一串“实际奖励比价值预测多了多少”的残差，估计当前动作相对平均行为的优势，在较短的价值估计和较长的实际回报之间做权衡。公式中的 $`r_t`$ 是当前奖励，$`V(s_t)`$ 是前缀状态的预测回报，$`\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)`$ 是一步时间差分残差。

从序列末尾往前，可以用 $`\hat A_t=\delta_t+\gamma\lambda\hat A_{t+1}`$ 递推。比如两个残差分别是 0.2、0.5，$`\gamma=1`$、$`\lambda=0.9`$，第一步优势就是 $`0.2+0.9\times0.5=0.65`$。$`\gamma`$ 决定任务回报怎样折扣未来，$`\lambda`$ 决定优势估计多依赖后续实际信号，两者不能当作同一个参数。

较小的 lambda 更依赖局部价值预测，通常方差较低，但价值模型不准会带来偏差；接近 1 时更接近完整回报减基线，通常方差更高。这个权衡依赖价值准确性和任务，不是所有情况下严格单调的结论。奖励和旧价值构造出的优势通常要停止梯度，避免反传到目标本身。

真实结束时后续价值应为零；达到最大长度的截断是否仍要用末状态估计未来，要按任务语义确定，padding 也要排除。终止和截断处理错了，公式再正确也会错。常见结果奖励 GRPO 使用组内相对评分，通常没有价值 Critic 和 GAE，不应把组优势称为同一个估计器。

```math
\begin{aligned}\hat A_t^{\mathrm{GAE}}&=\sum_{l\geq 0}(\gamma\lambda)^l\delta_{t+l}\\\delta_t&=r_t+\gamma V(s_{t+1})-V(s_t)\end{aligned}
```

#### 易错点

- Gamma 定义回报折扣，lambda 控制优势估计跨度；结果奖励 GRPO 通常不使用 GAE。

#### 追问

- 生成被 `max_tokens` 截断时怎样处理末状态价值？

<a id="aln-005"></a>
### ALN-005 · RLHF 的 KL 惩罚与 PPO 新旧策略约束有什么区别？

**L2** · 字节跳动

#### 答案

参考策略 KL 是限制模型长期偏离原有行为，新旧策略约束是限制某一轮更新走得太快，两者参照对象和目的不同。RLHF 常把冻结的 SFT 模型当参考策略 $`\pi_{\rm ref}`$，优化期望奖励减去 $`\beta D_{\rm KL}(\pi_\theta\Vert\pi_{\rm ref})`$；$`\beta`$ 控制行为漂移的代价。

PPO 的旧策略 $`\pi_{\rm old}`$ 是本轮采集轨迹时的策略，下一轮会刷新。Clip 或新旧 KL 让这批旧样本只被有限复用，避免一次更新过猛。可以理解为参考策略是出发点，旧策略是上一步：每次只迈一小步，走很多步仍可能离出发点很远，所以局部限制不能替代参考 KL。

实际中可用采样 token 的 log-prob 差估计参考 KL，即当前策略 log-prob 减参考 log-prob。单个样本项可能为负，正确采样下的期望才对应非负 KL；还要区分奖励里加入 KL 与显式损失里加入 KL，避免重复计算。参考系数大可能压制任务奖励提升，太小又可能放大奖励过优化。

调参需要联合观察参考 KL、独立正确率或胜率、熵和回答长度，也可以按目标 KL 调节系数。KL 约束只能控制相对分布变化，不能保证事实正确或修补坏奖励。PPO 的参考 KL 系数、clip 区间和 DPO 的 beta 进入目标的方式不同，数值不能直接互相复制。

#### 易错点

- KL 惩罚不能保证事实正确或彻底阻止 reward hacking。

#### 追问

- 为何增大 $`\beta`$ 可能伤害偏好奖励提升？

<a id="aln-008"></a>
### ALN-008 · PPO 与 DPO 在工程上如何选型？

**L2** · 字节跳动

#### 答案

已有可靠离线偏好对时，DPO 通常适合做较便宜、容易复现的基线；需要在当前模型上探索新行为，且能给出可信奖励时，PPO 更值得尝试。选型取决于反馈来源、候选覆盖和系统成本，没有脱离条件的绝对优劣。

DPO 主要读取固定的优选和非优选答案，训练循环接近监督学习，但如果旧候选没覆盖当前模型的错误，继续拟合也未必解决新问题。PPO 要生成轨迹、计算奖励和参考概率，再用价值模型构造优势并更新，在线采样能发现新行为，也可能进入评分器不可靠的区域。Critic 和 GAE 有助于控制优势方差，但增加模型训练、显存和调参开销。

比如一个问答任务有丰富高质量人工比较数据，先做 SFT 与 DPO 能快速评估偏好收益；代码任务若偏好很少、测试可靠，则在线奖励优化可能更合适。比较应使用相同初始模型、业务评测和推理预算，并把生成、打分和价值训练成本都算进去。在线奖励涨得快可能是投机，离线偏好准确率高也可能是过拟合。

我会先建立可复现基线，再判断在线增益是否值得复杂度。不能用更强 SFT 起点的 DPO 和更弱起点的 PPO 证明算法排序，也不能把某次不稳定训练归结为 PPO 必然不行。

#### 易错点

- “PPO 一定更强”或“DPO 一定更稳定”都缺少条件。

#### 追问

- 奖励可执行验证且偏好很少时，你会优先试哪条路线？

<a id="aln-025"></a>
### ALN-025 · RLHF-PPO 的四模型完整流程是什么？Critic 的 V_target 从哪里来？

**L2** · 字节跳动 / 阿里巴巴 / 阶跃星辰

#### 答案

经典 RLHF-PPO 的四个角色分别是生成答案的 Actor、预测后续回报的 Critic、提供行为锚点的 Reference，以及给完整答案打分的奖励模型 RM。RL 阶段通常更新前两者，冻结后两者；四个角色不意味着四套模型都同时训练，也不要求它们同尺寸或物理上完全独立。

一轮先用采样旧策略生成回答，缓存 token、有效 mask、旧 log-prob 和旧价值。RM 对完整回答评分，常在终点给任务奖励，并按约定把旧策略相对参考的 token log-prob 差作为 KL 惩罚并入奖励。公式中的 $`\tilde r_t`$ 是组合后奖励，beta 是参考惩罚系数，$`s_t`$ 是生成前缀，$`V_{\rm old}`$ 是采样时保存的价值。

然后从末尾向前计算 GAE，构造 $`V_{\rm target}=\mathrm{sg}(V_{\rm old}+\hat A)`$。它是这批数据上的回报估计，不是把 RM 分数直接复制到所有位置，也不是新 Critic 自己给自己当标签。例如最后奖励为 1、gamma 和 lambda 都为 1 且真实终止时，回报可传播到前面的前缀；有折扣、KL 和 bootstrap 时，各位置目标会不同。

Actor 优化 PPO 裁剪代理目标，Critic 用均方误差回归冻结目标，可另加 value clipping。有限次小批更新后刷新采样策略。只有有效回答位置参与相应训练，终止与截断、价值归一和 KL 放在奖励还是损失，都要一致。Reference 是固定锚点，old policy 是每轮快照；把两者混同，或让目标通过旧价值反传，都会破坏预期训练语义。

```math
\begin{aligned}\tilde r_t&=r_t^{\mathrm{task}}-\beta(\log\pi_{\mathrm{old}}(y_t\mid s_t)-\log\pi_{\mathrm{ref}}(y_t\mid s_t))\\ \hat A_t&=\delta_t+\gamma\lambda\hat A_{t+1},\quad \delta_t=\tilde r_t+\gamma V_{\mathrm{old}}(s_{t+1})-V_{\mathrm{old}}(s_t)\\ \hat V_t^{\mathrm{target}}&=\mathrm{sg}(V_{\mathrm{old}}(s_t)+\hat A_t)\\ \mathcal L_V&=\tfrac12\mathrm{mean}_{t\in\mathcal V}(V_\phi(s_t)-\hat V_t^{\mathrm{target}})^2\end{aligned}
```

四个角色不要求四份独立物理模型；图示经典 Actor 与 Critic 分开训练的流程。

#### 易错点

- 优势和回归目标要停止梯度，固定 Reference 不能与每轮 old policy 混同。

#### 追问

- PPO actor loss 下降而独立胜率降低，先检查哪些日志？

<a id="aln-026"></a>
### ALN-026 · PPO 需要多少张 GPU，怎样估算四模型、rollout 与训练显存？

**L2**

#### 答案

PPO 需要多少张 GPU，要按各阶段的显存和吞吐预算估算，不能从“四模型”直接得出固定卡数。除了模型状态，还要包括生成时的 KV 缓存、训练激活、轨迹缓存、通信缓冲和可能独立的推理权重副本。

可训练 Actor、Critic 在常见混合精度 Adam 设置下，每参数可粗估 16 字节：2 字节参数、2 字节梯度、4 字节主权重和两个各 4 字节状态。冻结 BF16 的 Reference 和 RM，权重约每参数 2 字节，没有同样的训练状态。若四者都是 7B，未分片时仅这些状态就是 $`2\times7\times16+2\times7\times2=252`$ GB 十进制，还没算激活或缓存。这只是说明状态量级，不能据此平均到几张卡后就保证装得下。

公式用 max 表示要看 rollout、打分、更新各阶段的实际峰值，能复用显存的串行角色与同时驻留的角色不同。ZeRO 或 FSDP 减少常驻状态，但临时聚合权重和通信峰值仍要加；LoRA、量化、无主权重或压缩优化器又需改算。生成引擎若保留独立 Actor 副本，也不能漏掉。

长回答首先可能在 rollout 的 KV 缓存上溢出，训练则可能受激活或优化器限制，两者优化方向不同。先列明参数规模、精度、组数、长度、并行分片和调度，再用小批实测各阶段峰值与余量。共卡、分卡及 CPU 卸载都要同时评价吞吐，最终卡数由这些约束共同决定。

```math
M_{\mathrm{peak}}\approx\max_{\mathrm{phase}}\big(M_{\mathrm{train\ states}}+M_{\mathrm{frozen\ weights}}+M_{\mathrm{activations}}+M_{\mathrm{KV}}+M_{\mathrm{buffers}}\big)
```

#### 易错点

- 峰值按实际驻留与阶段调度计算，不能把全部模型状态理想均分后直接承诺卡数。

#### 追问

- 长响应先在 rollout OOM、短响应在 update OOM，优化策略为何不同？

## DPO 与偏好数据

<a id="aln-006"></a>
### ALN-006 · DPO 的损失如何从 KL 正则化 RLHF 目标推出？

**L3**

#### 答案

DPO 的推导是把“奖励更高、又别离参考策略太远”的目标，转换成直接比较两条回答相对概率的损失，省去先训练独立奖励模型的步骤。关键不是只提高优选回答的概率，而是提高它相对参考模型的概率变化，并与非优选回答做比较。

从 $`\mathbb E[r]-\beta D_{\rm KL}(\pi\Vert\pi_{\rm ref})`$ 出发，最优策略满足 $`\pi^*(y\mid x)=\pi_{\rm ref}(y\mid x)\exp(r/\beta)/Z(x)`$，$`Z(x)`$ 用来归一化。取对数并整理，得到奖励等于 $`\beta\log(\pi^*/\pi_{\rm ref})+\beta\log Z(x)`$。再用 Bradley–Terry 的分数差描述同问题回答偏好，两个回答都有相同的 $`Z(x)`$，所以这一项抵消。

公式中 $`y_w`$ 是优选回答，$`y_l`$ 是非优选回答，$`\pi_\theta`$ 是待训练策略，$`\sigma`$ 是 sigmoid。假设优选回答相对参考提高了两倍，非优选不变，偏好 logit 就增加 $`\beta\log2`$。序列 log-prob 是有效回答各 token 的条件 log-prob 求和，提示词提供条件但不算作回答得分。取负 log-sigmoid，相当于拟合这条偏好标签。

推导需要 $`\beta>0`$、参考策略覆盖候选，以及对应的偏好模型假设。有限数据、模型容量和优化误差仍会限制训练；循环偏好也未必能被一个标量奖励完整表达。因此目标之间的理论联系，不等于 DPO 和任意 PPO 的实际训练过程、探索覆盖或最终效果完全相同。

```math
\mathcal{L}_{\mathrm{DPO}}=-\mathbb{E}_{(x,y_w,y_l)}\left[\log\sigma\left(\beta\left[\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\mathrm{ref}}(y_w\mid x)}-\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\mathrm{ref}}(y_l\mid x)}\right]\right)\right]
```

#### 易错点

- 理论目标的变换不保证有限数据的 DPO 与任意 PPO 训练得到同一结果。

#### 追问

- 当偏好出现循环时，BT 标量奖励假设有什么局限？

<a id="aln-007"></a>
### ALN-007 · DPO 的 β 和参考模型如何理解与调参？

**L2**

#### 答案

DPO 的参考模型决定“从什么行为出发”，beta 决定偏好分数的尺度，并与参考约束强度相关；调参不能只记成 beta 越大每步更新越小。参考模型通常选合适的 SFT 模型，并在训练时冻结，它不是每轮刷新一次的采样旧策略。

理论奖励加 KL 目标里，最优策略相对参考按 $`\exp(r/\beta)`$ 改变，beta 越大，固定奖励对分布的影响越弱。但 DPO 实际 loss 把 beta 乘到优选与非优选的 log-ratio 差上，梯度也受它影响。训练初期分数差为零时，梯度系数与 beta 成正比；后期 sigmoid 饱和又会削弱梯度。所以理论约束更强，不能直接推导有限训练中每步更小或最终 KL 必然单调下降。

例如两个参考模型对同一偏好回答的起始概率差很多，即使 beta 相同，相对变化和隐式奖励也不同。调参应固定数据、学习率和训练预算，扫描几组 beta，同时看偏好间隔、参考 KL、独立胜率及通用回归。还要检查参考与偏好数据的模板、候选生成分布和长度是否匹配。仅看到训练隐式奖励差变大，不足以确定业务效果更好。

#### 易错点

- 不要把 β 大简单解释成每步梯度必然更小。

#### 追问

- 同样 $`\beta`$，换参考模型为什么结果会变？

<a id="aln-009"></a>
### ALN-009 · 如何把点赞、点踩和日志变成高质量偏好数据？

**L2**

#### 答案

点赞、点踩和日志是偏好线索，要变成训练数据，首先得明确用户在评价什么，并让候选在相同条件下可比较。不同问题、不同用户的一条点赞与一条点踩，不能直接拼成同问题偏好对。

例如用户点踩可能因为答案事实错，也可能因为太慢、太长或不满足格式。应把这些原因尽量分开，记录问题、证据、工具结果和展示条件，再对同一上下文生成或匹配候选。若一个回答拿到了正确文档，另一个没有，比较会混入输入差异，不能当作回答能力的纯偏好。展示位置、曝光次数和长度也可能影响互动，需要抽查或控制实验。

标注时给出明确标准，允许平局、不确定和不可比较，不能为了凑对强选胜者；对优选回答还要验证内容真的正确。AI 裁判能降成本，但要用人工或独立规则估计噪声，特别检查偏向文风、同模型和较长答案的情况。训练测试按用户、文档、模板或时间隔离，并处理近重复。单条好坏标签可以用于相应方法，但它与同问题的相对偏好含义不同，转换时要保留这一边界。

#### 易错点

- 不能把不同用户不同问题的点赞答案与点踩答案直接配对。

#### 追问

- AI 评分生成偏好时怎样估计标注噪声？

<a id="aln-018"></a>
### ALN-018 · IPO、KTO 等偏好优化方法与 DPO 有何区别？

**L3** · 阶跃星辰

#### 答案

DPO、IPO 和 KTO 都用偏好反馈改变模型，但数据含义和损失不同：DPO、IPO 通常比较同问题的两条回答，KTO 可以直接使用单条回答的好坏标签。不能因为都避免在线 PPO，就把它们看成同一个目标的写法。

DPO 用优选与非优选回答相对参考模型的序列 log-ratio 差，经过 log-sigmoid 拟合比较标签。IPO 从更一般的偏好目标出发，用 identity 映射讨论确定偏好和有限数据下的过拟合及正则化，不是简单给 DPO 加一项 SFT。现实中的循环偏好未必能由单个标量奖励完美表示，也不能只凭名称判断谁更好。

KTO 的 $`s_\theta`$ 是回答相对参考模型的 log-prob 差，$`z`$ 是停止梯度的参考点估计，通常与 KL 有关。好样本希望 $`s_\theta`$ 高于参考点，坏样本希望低于参考点，用 sigmoid 效用构造损失；$`\beta`$ 控制曲线尺度，$`\lambda_D`$、$`\lambda_U`$ 控制两类权重。实际共享参考点可能通过错配问题与回答估计，再截为非负，它不是精确真实 KL，也不是给坏样本交叉熵乘负号。

例如两条答案都错了，其中一条少错一点，可以作为 DPO 的相对优选，却不应自动给它 KTO 的“好”标签。点赞日志自然是单条反馈，但仍需纠正曝光、问题难度和标签噪声。正负样本数量、采样比例与权重共同决定贡献，不能孤立宣称坏样本必须更大权重。比较时控制参考模型、数据和预算，联合看正确率、胜率、KL 和拒答表现。

```math
\begin{aligned}s_\theta(x,y)&=\log\frac{\pi_\theta(y\mid x)}{\pi_{\mathrm{ref}}(y\mid x)},\quad z=\mathrm{sg}(\hat z_0)\\\ell_{\mathrm{KTO}}(x,y)&=\begin{cases}\lambda_D[1-\sigma(\beta(s_\theta-z))],&y\ \mathrm{desirable}\\\lambda_U[1-\sigma(\beta(z-s_\theta))],&y\ \mathrm{undesirable}\end{cases}\\\mathcal L_{\mathrm{DPO}}&=-\mathbb E\log\sigma\!\left(\beta[s_\theta(x,y_w)-s_\theta(x,y_l)]\right)\end{aligned}
```

#### 易错点

- 相对优选不一定绝对合格，成对偏好与单条好坏标签不能直接互换。
- KTO 的停止梯度参考点不是额外可微 KL 惩罚的同义词。
- 正负贡献还取决于数量和采样，不能只看两个 loss 权重。

#### 追问

- 两个候选都错了但一个较好，如何分别为DPO与KTO标注？
- 点赞数据主要来自简单问题时，怎样避免KTO学习曝光/难度偏差？

<a id="aln-019"></a>
### ALN-019 · 离线偏好优化和在线 RL 的分布差异是什么？

**L2**

#### 答案

离线偏好优化学的是固定候选上的比较，在线 RL 则不断用更新后的模型生成数据，两者遇到的错误分布和探索空间不同。离线方式方便复现、成本可控，但候选可能越来越不像当前模型会产生的内容；在线方式能发现新行为，也会给评分器带来新的难题。

例如偏好集来自一个较弱模型，只包含明显事实错误，训练后的模型已经不犯这些错，却出现更隐蔽的引用错误，继续拟合旧数据可能帮助有限。在线采样能暴露新错误，但也可能探索到奖励模型没有见过的套话或投机回答。评估要看当前生成分布的独立质量，不能只看固定偏好集准确率。

可以迭代刷新候选与偏好，也有在线 DPO 等变体，所以 DPO 这个名字不永久等于固定离线数据。每次更新数据要保留版本和独立留出集，避免把新评测样本混进训练。在线训练还要控制采样策略与更新策略的滞后，有限复用时监测新旧概率比和 KL。选择要结合奖励可靠性、rollout 费用和任务反馈，而不是简单认为在线一定更强或离线永远更稳。

#### 易错点

- 在线 DPO 等变体存在，不能把 DPO 永久等同于固定离线流程。

#### 追问

- 怎样发现离线数据覆盖不足，而非优化器没收敛？

<a id="aln-042"></a>
### ALN-042 · 坏数据的 SFT loss 直接取负能代替 RL 吗，与 unlikelihood 有何区别？

**L2** · 阶跃星辰

#### 答案

坏样本的交叉熵直接取负，会压低这个目标的概率，但不是强化学习的等价替代，而且目标没有有限下界。坏目标概率为 $`p_b`$ 时，普通交叉熵是 $`-\log p_b`$，取负后最小化 $`\log p_b`$，当概率趋于零，损失趋于负无穷；梯度裁剪也不能改变这个性质。

Unlikelihood 用 $`-\log(1-p_b)`$，是非负的，坏概率趋零时损失也趋零。对于坏 token 的 softmax logit $`z_b`$，负交叉熵梯度是 $`1-p_b`$，unlikelihood 梯度是 $`p_b`$。例如坏概率已降到 0.01，前者梯度约 0.99，仍持续强压，后者约 0.01，惩罚自然减弱。Unlikelihood 有下界但没有有限上界，坏概率接近一时仍会发散。

可以把正确答案的最大似然损失与负候选集合 $`C_t`$ 的 unlikelihood 加权组合，alpha 是非负权重。负候选应定位明确错误、重复或不应输出的内容，不能把被点踩答案里的每个通用词都当坏 token。例如最后数字错了，应先看是否只惩罚数字位置。提示、填充和正确工具结果要按语义屏蔽，长度归约、正负采样比例和权重也要区分。实现应稳定计算 $`\log(1-p)`$，随意截概率会改变目标。

这些仍是固定数据上的监督约束。在线 RL 在策略采样的轨迹上按奖励和优势更新，还涉及采样分布、基线和策略限制；某一步负优势的梯度像负权重 log-prob，不代表整个固定坏数据训练等价 RL。局部明确错误可用修订示范或 unlikelihood，有可靠完整反馈且需要探索时，再比较 DPO、KTO 或在线 RL，并以独立任务质量验收。

```math
\begin{aligned}\mathcal L_{\mathrm{negCE}}&=\log p_b\longrightarrow-\infty\quad(p_b\to0)\\\mathcal L_{\mathrm{UL}}&=-\log(1-p_b)\ge0,\quad\lim_{p_b\to0}\mathcal L_{\mathrm{UL}}=0\\\frac{\partial\mathcal L_{\mathrm{negCE}}}{\partial z_b}&=1-p_b,\qquad\frac{\partial\mathcal L_{\mathrm{UL}}}{\partial z_b}=p_b\\\mathcal L&=\mathcal L_{\mathrm{MLE}}+\alpha\sum_{t}\sum_{c\in C_t}-\log(1-p_\theta(c\mid x_{\lt t})),\quad\alpha\ge0\end{aligned}
```

#### 易错点

- Unlikelihood 有下界但无有限上界，坏概率接近一时损失仍发散。
- 固定坏数据取负损失，缺少在线采样与奖励目标等条件，不能直接叫 RL。
- 整段坏答案里可能有正确部分，不能把每个词都惩罚。

#### 追问

- 一个回答只有最后一个数字错了，你会惩罚哪些位置？
- 若负例概率已经很小，负CE与unlikelihood为何仍产生不同梯度？

<a id="aln-010"></a>
### ALN-010 · GRPO 与 PPO 怎样计算优势，reward 和 advantage 有什么区别？

**L2** · 小红书 / 字节跳动 / 阶跃星辰 / 阿里巴巴 / 深势科技

#### 答案

Reward 是任务给出的分数，advantage 是这个动作或回答比基线好多少；PPO 常用价值网络估计基线，结果奖励 GRPO 则用同题多条回答互相比。分数为正不代表优势为正，例如同组奖励是 0.7、0.8、0.9，第一条虽然有正奖励，却低于组均值。

理论优势 $`A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s)`$，表示先选动作 $`a`$ 比当前状态下平均行动多得到多少回报。常见 PPO 用 Critic 预测每个前缀的 $`V`$，结合奖励计算时间差分残差，再用 GAE 汇总，因此一条回答的不同 token 可以有不同优势。公式中的 gamma 是折扣，lambda 控制估计跨度。

结果奖励 GRPO 对同一提示采样 $`G`$ 条回答，$`R_i`$ 是第 $`i`$ 条奖励，$`\bar R`$ 是组均值，减均值后再除组标准差得到相对优势，并把它赋给该回答的有效生成 token。它省去独立 Critic，但没有省去基线、采样和评分，也不是 GAE。把终态优势广播只是更新权重，并不说明每个词都同样导致成功；过程奖励版本还可能采用不同的优势定义。

数学、代码等结果可验证且组内有差异的任务较适合这种反馈；长交互和细粒度信用分配可比较价值网络或过程信号。$`G=1`$ 或全组同分时没有有效相对信号，epsilon 只能防除零。组大小、标准差归一和回答长度会影响成本与梯度权重，去掉 Critic 不能直接推出总成本降低某个固定比例。

```math
\begin{aligned}A^\pi(s,a)&=Q^\pi(s,a)-V^\pi(s)\\\delta_t&=r_t+\gamma V(s_{t+1})-V(s_t),\quad\hat A_t^{\mathrm{PPO}}=\sum_{l\ge0}(\gamma\lambda)^l\delta_{t+l}\\\hat A_{i,t}^{\mathrm{GRPO}}&=\frac{R_i-\bar R}{\mathrm{std}(R_1,\ldots,R_G)+\epsilon}\quad\mathrm{(outcome\ reward)}\end{aligned}
```

#### 易错点

- 给整条回答的 token 同一优势，只说明更新权重，不说明各词的因果贡献相同。
- 省去价值 Critic 不等于没有基线、奖励器或 rollout，过程奖励还可采用不同优势。

#### 追问

- 组奖励为0.7、0.8、0.9，为何0.7的reward为正但advantage为负？
- 多轮Agent只有最后是否成功，如何改善sample-level反馈的信用分配？

<a id="aln-011"></a>
### ALN-011 · GRPO 组内标准差归一化带来哪些问题？

**L3**

#### 答案

GRPO 除以组内标准差，除了统一优势尺度，还会给不同问题重新分配训练权重，所以它不只是一个无害的数值归一化。减组均值回答“比同题平均好多少”，除标准差回答“这点差异相对于本组波动有多大”。

公式 $`\hat A_i=(R_i-\bar R)/(\mathrm{std}(R)+\epsilon)`$ 中，$`R_i`$ 是回答评分，$`\bar R`$ 是同题组均值，epsilon 是防止分母为零的小量。例如两个问题的奖励差都只有 0.1，但一个组整体波动很小，另一个波动很大，前一个问题可能得到更大的归一化信号。二元正确性奖励的方差又与成功率有关，因此这种缩放会引入问题难度相关的重加权，而不保证是原始奖励目标的无偏梯度。

全对或全错时，减均值已经得到全零，增加 epsilon 不会创造信号。组大小影响方差估计，也影响能否采到既对又错的回答；连续多维奖励还要先检查各分项量纲。可以比较取消标准差缩放、使用全 batch 尺度或调整难度采样，但这些会改变梯度尺度或数据分布。实验要控制总采样量和训练预算，并联合看非零优势组比例、独立正确率与更新稳定性，不能只因为 loss 更平滑就判断更好。

#### 易错点

- 除组标准差会重加权不同问题，并不天然是原奖励目标的无偏梯度。

#### 追问

- 奖励为连续多维分数时，量纲怎样影响组优势？

<a id="aln-012"></a>
### ALN-012 · GRPO 的长度偏差与 Dr. GRPO 有什么关系？

**L3**

#### 答案

GRPO 的长度偏差主要来自怎样把 token 损失汇总成回答损失，不能简单说它总偏爱短回答。若每条回答先除自己的长度，再对回答平均，短回答中每个 token 的权重更大；对负优势回答，长答案的单个 token 惩罚就较小。

例如两条回答长度分别为 10 和 100，都采用逐回答 token 平均，前者每个 token 权重是后者十倍。正优势下，短答案的局部概率得到更强推动；负优势下，较长错误回答的单 token 概率被压得较弱。再加上序列生成的联合概率和采样过程，就可能造成复杂长度效应，不能只观察平均长度便断言一种方向。

Dr. GRPO 讨论去掉逐回答长度归一和组内标准差缩放，用常数尺度汇总，让这些数据相关分母不再改变权重。常数分母、全 batch 有效 token 平均，以及先逐回答平均，是三种不同目标。全 batch token 平均在一批里给所有 token 相同权重，但较长回答会贡献更多 token，并且分母仍随采样长度变化。

比较时必须固定回答 mask、EOS、截断规则、采样长度和奖励，联合看正确率、长度分布与超长比例。某种归约修正有收益，不意味着它对所有希望优化的目标都无偏或更优；先说明目标是按回答等权、按 token 等权，还是原始序列奖励的策略梯度。

#### 易错点

- 归约方式是否合适要相对明确目标判断，不能把一种修正称为所有目标下无偏。

#### 追问

- 全 batch token mean 会怎样改变样本之间的相对权重？

<a id="aln-013"></a>
### ALN-013 · RLVR 的可验证奖励如何设计？

**L2** · 字节跳动 / 深势科技

#### 答案

RLVR 用可执行验证器给模型奖励，让最终对错成为训练反馈，例如检查数学答案或运行代码测试。它减少主观逐条评价的需求，但验证器能检查什么，模型就可能优化什么，必须确认这个范围接近真实任务。

数学题要处理分数、表达式等价、单位和解析失败，不能只做字符串匹配。代码题要隔离执行环境，设置超时，加入边界与隐藏测试；几条公开用例通过，不代表所有输入都正确。例如只奖励返回某个固定测试答案，模型可能学会硬编码，而没有学会算法。格式与内容奖励最好分开，否则正确括号和标签可能比真实答案更容易得分。

应先用正确、错误、格式异常和对抗样本测试验证器，再检查训练中的高分失败案例，并用独立题目验收。工具执行成功也不等于业务目标完成，例如接口返回 200，但写入的内容错了，最终奖励仍应反映目标。结果可验证不代表推理过程每步可靠，也不意味着无需任务标签：正确答案、测试或环境成功条件往往就是评分依据。验证器不是完备真理 oracle，弱规则和环境漏洞仍可能被利用。

#### 易错点

- 一个正则或少量公开测试不是完备的 correctness oracle。

#### 追问

- 工具调用成功但业务目标未完成，应怎样给奖励？

<a id="aln-014"></a>
### ALN-014 · ORM 与 PRM 的区别和信用分配难点是什么？

**L2**

#### 答案

ORM 给整段答案或最终结果评分，PRM 给中间步骤评分；后者能更早指出错误，但需要清晰步骤边界和可靠过程标准。信用分配问题就是：最终成功或失败，究竟该归功或归责于哪些动作。

例如十步解题最后错了，ORM 只给零分，模型不知道哪一步出了问题；PRM 可能指出第五步推导不成立，提供更细的反馈。但步骤看起来合理并不保证整条链正确，局部正确也不一定有助于最终目标。步骤怎么切、怎样聚合分数，会改变训练或候选排序效果，还可能鼓励模型把一步拆成多步来迎合评分。

结果奖励可以只在末尾给出，再通过回报或 GAE 得到各 token 的优势，这不等于这些 token 获得了真实过程奖励。同一分数广播到所有 token，也不是因果归因。步骤奖励、token 奖励、序列评分和损失归约分别描述不同粒度，不能混为一谈。

过程模型用于训练和用于推理筛选，需要分别验证。Agent 的检索、工具参数、结果使用等步骤可以有各自标准，但局部工具成功不能替代端到端目标。PRM 增加标注和评估成本，也可能存在误判或漏洞，不能声称彻底解决信用分配，更不能把数学实验收益直接外推到所有开放任务。

#### 易错点

- 步骤看似合理不代表整个推理或最终结果正确。

#### 追问

- Agent 的检索、工具、答复步骤如何构造过程评分？

### ALN-027 · GSPO 与 GRPO 的 importance ratio、clip 和梯度单位有什么区别？

**L3** · 阿里巴巴 / 深势科技

#### 答案

GRPO 常对每个 token 单独计算新旧概率比，GSPO 则先把一整条回答的概率变化汇总成一个长度归一比例，再对整条回答裁剪，使更新单位更接近序列评分单位。两者都可以用同题多回答的组内优势，但 clip 的对象和梯度权重不同。

公式中 $`y_i`$ 是第 $`i`$ 条回答，$`|y_i|`$ 是有效长度，$`s_i`$ 是序列比例。它先求各 token 的新旧 log-prob 差，取平均，再指数化，等于原始序列概率比的 $`1/|y_i|`$ 次方。比如两个 token 的比率是 4 和 0.25，几何平均是 1；GSPO 的序列比例可能接近 1，但 token 级 GRPO 会分别看到极端上升和下降。长度归一能控制数值范围，却也改变了原始轨迹重要性权重。

在未裁剪区域，一条回答的 token 梯度共享 $`s_i\hat A_i`$，并带有 $`1/|y_i|`$ 的尺度；不是只把普通 token loss 最后取平均。因比率定义不同，不能直接沿用相同 epsilon。实现要在 log 空间算，避免长序列概率直接相乘下溢，并检查有效 mask 和旧策略版本。

专家混合模型还要关注旧新策略的专家路由变化，它会造成 log-prob 剧烈波动；Routing Replay 可以缓存并重放旧路由，但增加缓存、通信并限制路由自由度。序列级方法在部分设置里更稳定，不代表所有专家模型都保证收敛，也不代替负载均衡。应先排除训推精度、内核和模板差异，再按相同采样与奖励预算比较独立质量、裁剪比例和策略漂移。

```math
\begin{aligned}s_i(\theta)&=\exp\left(\frac{1}{|y_i|}\sum_t\log\frac{\pi_\theta(y_{i,t}\mid x,y_{i,\lt t})}{\pi_{\mathrm{old}}(y_{i,t}\mid x,y_{i,\lt t})}\right)\\ J_{\mathrm{GSPO}}&=\mathbb E\left[\frac1G\sum_i\min(s_i\hat A_i,\mathrm{clip}(s_i,1-\epsilon,1+\epsilon)\hat A_i)\right]\end{aligned}
```

#### 易错点

- GSPO 改变了比率和裁剪单位，不能概括成普通 token loss 最后取平均。

#### 追问

- 两个响应某个 token 的 ratio 极端，但序列均值接近1，GSPO与GRPO会怎样不同？
- RL训练MoE为何需要关注旧/新策略的专家选择？
- Routing Replay有什么缓存和优化自由度代价，GSPO能否保证所有MoE收敛？

### ALN-028 · DAPO 相比原始 GRPO 改了什么，四个核心设计分别解决什么问题？

**L3** · 阿里巴巴

#### 答案

DAPO 是围绕大规模推理强化学习的一组协同设计，重点包括放宽上侧裁剪、筛选有差异的采样组、按 token 汇总损失，以及更合理地处理超长回答。它不是只把 GRPO 的一个优势公式换掉。

Clip-Higher 把上下界分开，对正优势动作增加概率的上边界放宽，减少探索过早受限，同时保留下侧限制。动态采样过滤同题全对或全错等同分组，继续生成直到补够有区分度的训练数据。例如每题采四条但全错，相对优势都是零，过滤后改用有对有错的组，可增加有效信号；代价是更多生成，并改变问题难度分布。

Token 级损失把整批有效生成 token 一起归一化，公式中的 $`m_{i,t}`$ 表示第 $`i`$ 条回答第 $`t`$ 个 token 有效，$`\rho`$ 是该位置的新旧比率。它不同于先按每条回答长度平均再平均回答，所以长短回答的相对贡献会变化。超长处理则用长度缓冲区和逐渐增加的惩罚，缓解硬截断把“还没答完”直接误当完整失败的归因。

这些选择需要共同检查熵、非零优势组比例、长度、截断和留出正确率。不对称 clip 是允许更新区间不同，不等于正负样本乘不同权重。某个 recipe 去掉显式 KL，也不能推广为所有任务都不需要行为约束；上侧放得太宽可能仍导致不稳定，训练奖励提高也不能替代独立验收。

```math
J\propto\frac{\sum_{i,t}m_{i,t}\min(\rho_{i,t}\hat A_i,\mathrm{clip}(\rho_{i,t},1-\epsilon_{\mathrm{low}},1+\epsilon_{\mathrm{high}})\hat A_i)}{\sum_{i,t}m_{i,t}}
```

#### 易错点

- 不对称clip上下界不等于给正负样本直接乘不同数据权重。

#### 追问

- 过滤全对/全错组会对样本难度和每步采样成本产生什么影响？

### ALN-029 · 在 verl 中支持 DAPO，需要改哪些配置或训练模块？

**L3**

#### 答案

在 verl 中实现 DAPO，需要把采样筛选、奖励处理和 Actor 损失都接起来，仅改一个优势估计器不足以实现完整训练。先锁定框架版本和 recipe，再确认对应配置真正到达这些模块，因为字段和默认行为可能随版本变化。

Actor 侧需要分别设置 `clip_ratio_low` 和 `clip_ratio_high`，即新旧比率的上下裁剪幅度，并用 `loss_agg_mode` 选择全批有效 token 平均。数据侧启用 `filter_groups`，按准确率或指定评分判断同题是否全同，并在筛选后继续生成，直到达到训练问题数或生成上限。`gen_batch_size` 是候选生成批次，`train_batch_size` 是保留训练问题批次，还要乘每题 rollout 数才能得到轨迹数。

奖励侧的 `overlong_buffer` 定义回答长度缓冲与惩罚。例如允许最长 1000 token、缓冲 200，则超过 800 后逐步加惩罚，不能把 padding 当有效长度。如果当前训练器没有过滤后补采样的循环，就需要修改 rollout 收集与组筛选；clip 和归约改 Actor loss，长度惩罚改奖励路径，不能都塞进一个配置项。

先用小批验证组编号、mask、边界和非零优势，再逐项开启并做对照。某些 recipe 有超长奖励 shaping，却不包含额外的 Overlong Filtering，两者不能因为名称近似就算作已复现。复现边界按锁定版本确认，不假设所有未来版本永久相同。若一直采不满训练批，优先查题目难度、奖励解析和采样多样性，而不是无限增加生成次数。

#### 易错点

- “DAPO=GRPO+调高epsilon”漏掉数据选择、loss归一化和奖励路径。

#### 追问

- 启用filter_groups后一直采不够批次，应检查数据难度、奖励还是采样策略？

### ALN-030 · GRPO 数据必须标注 Thought 吗，完整训练数据与 rollout 怎样组织？

**L2** · 小红书 / 字节跳动

#### 答案

GRPO 不要求训练数据必须有人写好的 Thought，它主要需要问题和能给模型生成结果打分的信息。推理文本可以由当前模型自己采样，奖励来自答案、测试或环境，而不是把每条人工推理都当监督标签。

例如数学训练保存题目和可核验答案，代码保存任务及测试环境，Agent 保存初始状态和成功判定。每轮对同一问题生成 $`G`$ 条回答，评分后计算组内相对优势，再用对应轨迹更新策略。若先做冷启动 SFT，则那一阶段需要高质量目标回答，可以带推理过程；它与在线 GRPO 的输入要求不同。过程奖励可以使用步骤标签或验证器，但不是 GRPO 的强制字段。

实现要保留问题组编号、有效回答 mask、终止或截断信息、旧策略 log-prob 和奖励。不能把不同问题混为一组，奖励与优势通常停止梯度，组标准差、损失归约和 KL 位置按实现明确。$`G=1`$ 通常无法提供组内相对信号；全错时，增加人工推理文本不自动改变这轮零优势，可能需要改善初始化、题目难度、探索或奖励反馈。不能说 GRPO 完全不需要标签，它只是通常不需要人工逐 token 的推理标签。

#### 易错点

- “GRPO不需要数据标签”过于绝对：可验证奖励常需要答案/测试/环境信息，只是不必人工Thought。

#### 追问

- 模型全部回答错误时，为什么改成更多人工推理文本未必解决GRPO零优势？

### ALN-031 · GRPO 不收敛或训练奖励升高但能力退化，怎样排查和调参？

**L3** · 小红书 / 字节跳动

#### 答案

GRPO 不收敛时，先确认它有没有可靠且有差异的学习信号，再检查梯度和更新；奖励上涨而能力退化时，先怀疑评分被利用或目标错配，不能只继续训练。策略梯度 loss 接近零，可能是全组同分、裁剪饱和或代码没更新，并不证明收敛。

先离线重放正确、错误、格式异常和截断样本，核验解析、测试超时及分项奖励。再看全对全错组比例、组内方差和重复回答。如果题太难，全错没有相对信号；太容易也可能全对。检查组编号、回答 mask、预测与 token 对齐、停止梯度和归一化。在真正更新前，同权重的新旧策略比率应接近 1；如果不接近，先查模板、精度和训推内核，而不是调学习率。

监控独立正确率、熵、参考 KL、裁剪比例、梯度范数、长度和截断。熵坍缩表示模型分布过快集中，组内回答近似相同，探索变差；它与低温解码人为减少多样性不同，可在固定采样设置下检查原始熵和组内重复率。回答更长也可能只是迎合奖励，不是更会推理。

先用能生成对错混合的小任务跑通，再单变量调整学习率、每批更新轮数、clip、KL、组数、温度和长度预算。恢复探索要同时看任务成功，不是随机词越多越好。若独立质量持续下降，回滚并定位奖励或优化原因；更宽 clip、更多采样和更长训练都不是通用修复。

#### 易错点

- 策略损失接近零可能是没有优势或没有有效更新，不足以判断训练成功。

#### 追问

- 组内奖励有方差但ratio始终1且权重不变，如何定位未更新问题？
- 怎样区分策略本身的熵下降、低温解码和奖励驱动的模式坍缩？

### ALN-032 · 正负样本不对称设计有哪些方式，和 PPO/DAPO 的不对称 clip 有何区别？

**L3**

#### 答案

正负样本不对称可以通过采样、损失权重或更新限制实现，但首先要说明“正负”指类别标签、偏好对，还是优势符号。它们含义不同，不能都用一句“提高负样本权重”来解释。

分类中可用加权二元交叉熵，公式里的 $`y`$ 是 0/1 标签，$`p`$ 是正类概率，$`w_+`$、$`w_-`$ 控制两类误差成本。例如漏报高风险事件更贵，可以增加相关类贡献，但实际效果还受类别数量、采样和决策阈值影响。DPO 的优选与非优选是同问题相对比较，标准目标已推动两者的参考 log-ratio 间隔；若再分别拉高或压低绝对概率，就改变了目标，可能引入长度和遗忘问题。

PPO 或 DAPO 的不对称 clip 则改变概率比允许获得收益的区间。$`A>0`$ 时限制过度增加动作概率，$`A<0`$ 时限制过度减少；$`\epsilon_{\rm low}`$ 和 $`\epsilon_{\rm high}`$ 是两侧范围，不是两类样本的常数权重。同一个样本在区间内外的梯度行为会变化，而直接乘权重是整体缩放贡献。

选型应对应明确业务代价，并报告正负分层效果和误伤。例如提高拒答相关贡献后，要确认合法请求没有大幅被拒。数据比例、长度归约、样本可信度和阈值也要一起记录，不能只比较某个权重数值。

```math
\begin{aligned}\mathcal L_{\mathrm{weighted\ BCE}}&=-\mathbb E[w_+y\log p+w_-(1-y)\log(1-p)]\\ \ell_{\mathrm{PPO}}&=\min(\rho A,\mathrm{clip}(\rho,1-\epsilon_{\mathrm{low}},1+\epsilon_{\mathrm{high}})A)\end{aligned}
```

#### 易错点

- 不能把类别权重、chosen/rejected概率项、正负优势clip三种机制当作同一算法。

#### 追问

- 高风险拒答任务怎样验证提高负类权重没有导致过度拒答？

### ALN-040 · Flow-GRPO 怎样训练图像生成模型，如何把 ODE 转成保持边缘分布的 SDE？

**L3** · 小红书 / 美团 / 快手

#### 答案

Flow-GRPO 把图像生成的每次去噪更新当作动作，用最终图像评分来改进整条生成轨迹；为了计算动作概率，它把确定性的流 ODE 转成有随机转移密度的 SDE。同题采多条图像，计算组内优势，固定旧轨迹与旧 log-prob，再用当前概率比、裁剪和参考约束更新模型，不必训练独立 Critic。目标中 $`G`$ 是每题轨迹数，$`T`$ 是有效随机步骤数，$`\eta`$ 是比率裁剪幅度，$`\beta`$ 是参考 KL 权重。

状态包括提示 $`c`$、时间 $`t`$ 和当前 latent $`x_t`$，动作是下一个 latent。结果奖励可以检查物体、属性、空间关系、文字或整体偏好。Rectified Flow 常用 $`x_t=(1-t)x_0+t\epsilon`$：$`x_0`$ 是图像，$`\epsilon`$ 是噪声，生成从 $`t=1`$ 向零积分。$`v_t`$ 是从图像向噪声方向的速度场，$`v_\theta`$ 是模型预测，$`p_t`$ 是该时刻 latent 的概率密度。不同初始噪声产生不同图像，但固定当前状态后，ODE 下一步是确定的，属于 Dirac 转移，不能当普通高斯密度套 PPO 比率。即便能计算输出边缘密度，也不等于得到了这里需要的条件转移密度。

保持连续时间边缘分布，不能只加噪声，还要修正漂移。令递增采样时钟 $`u=1-t`$、$`q_u=p_{1-u}`$，原漂移 $`b_u=-v_{1-u}`$，添加时间相关噪声 $`\sigma_t`$ 时，漂移改为 $`b_u+\sigma_t^2\nabla\log q_u/2`$。Score $`\nabla\log q_u`$ 是分布对位置的对数梯度；Fokker–Planck 方程中，新增 score 漂移与扩散项相消，剩下原 ODE 的连续性方程。线性高斯插值可得 score 为 $`-[x+(1-t)v_t(x)]/t`$，代入就得到公式中的均值。

用正步长 $`h`$ 从 $`t`$ 更新到 $`t-h`$，加入 $`\sigma_t\sqrt h\,z`$，$`z`$ 为标准高斯噪声，转移就成为均值 $`\mu_\theta`$、协方差 $`\sigma_t^2hI`$ 的高斯，可计算 log-prob。常用 $`\sigma_t=a\sqrt{t/(1-t)}`$，$`a`$ 控制随机强度。精确 score、相同初始分布和连续时间才支撑同边缘结论；近似速度、Euler 离散化和端点处理都有误差，同边缘也不代表同轨迹。$`t=1`$ 的分母发散、$`t=0`$ 的除法都要处理，零方差步骤不能用普通高斯概率比。

工程中，递减时间的 $`dt`$ 为负，噪声尺度应使用 $`\sqrt{-dt}`$，不能直接开平方负数。均值和 log-prob 常用 FP32；有的实现把 latent 各维 log-prob 取平均，得到维度归一比例，而联合密度应求和，改变归约就改变 clip 和 KL 的尺度。奖励与优势停止梯度，不需要让评分器梯度穿过整条生成链。

减少训练去噪步数可以降低采样成本，评测仍可用原推理日程，不能把训练少步图像质量当最终质量。验证同权重新旧比率接近一、分组、调度与条件引导一致，同时测画质和多样性，防止只提高评分。扩展到视频还要区分帧轴与去噪时间轴，重新设计动作、奖励和资源实验，不能由图像结果直接保证视频收益。

```math
\begin{aligned}q_u&=p_{1-u},\quad b_u=-v_{1-u},\quad s_t=\nabla\log p_t\\ \partial_u q_u&=-\nabla\!\cdot[(b_u+\tfrac12\sigma_t^2\nabla\log q_u)q_u]+\tfrac12\sigma_t^2\Delta q_u=-\nabla\!\cdot(b_uq_u)\\ \mu_\theta(x_t,t,h,c)&=x_t-h\left[v_\theta(x_t,t,c)+\frac{\sigma_t^2}{2t}\big(x_t+(1-t)v_\theta(x_t,t,c)\big)\right]\\ x_{t-h}&=\mu_\theta+\sigma_t\sqrt h\,z,\quad z\sim\mathcal N(0,I),\quad h\gt 0\\ \pi_\theta(x_{t-h}\mid x_t,t,c)&=\mathcal N(\mu_\theta,\sigma_t^2hI)\\ \hat A_i&=\frac{R_i-\bar R}{\mathrm{std}(R)+\epsilon},\quad \rho_{i,t}=\exp(\log\pi_\theta-\log\pi_{\mathrm{old}})\\ J&=\mathbb E\left[\frac1G\sum_i\frac1T\sum_t\left(\min(\rho_{i,t}\hat A_i,\mathrm{clip}(\rho_{i,t},1-\eta,1+\eta)\hat A_i)-\beta D_{\mathrm{KL}}(\pi_\theta\Vert\pi_{\mathrm{ref}})\right)\right]\end{aligned}
```

#### 易错点

- 递减采样时间的噪声尺度用正步长开方，同边缘分布也不代表相同轨迹。
- 旧轨迹与旧概率应固定，结果奖励可以不可微，不需要沿整条 ODE 反传评分器梯度。

#### 追问

- 若只在部分步加噪声，哪些步能参与概率比更新，和原始全SDE方案有何区别？
- 把latent维log-prob的mean换成sum，为什么概率比、clip fraction和KL尺度都会改变？

<a id="aln-041"></a>
### ALN-041 · RLOO 如何计算 leave-one-out 基线，与 GRPO、PPO 有什么区别？

**L2** · 阶跃星辰

#### 答案

RLOO 用同题其他回答的平均奖励作当前回答的基线，让完整回答的策略梯度更稳定，并避免基线直接包含自己的评分。每题需要独立采样 $`G\ge2`$ 条回答，$`R_i`$ 是第 $`i`$ 条奖励，$`b_i`$ 是其余 $`G-1`$ 条的平均值，优势 $`A_i=R_i-b_i`$。

例如两条奖励分别是 1 和 0，两条优势就是 1 和 -1；若直接减包含自身的组均值，则只有 0.5 和 -0.5。一般有 $`A_i=G(R_i-\bar R)/(G-1)`$。在 on-policy 更新点、同题独立采样和奖励停止梯度条件下，其他回答基线不依赖当前回答动作，乘当前 log-prob 梯度的期望为零，因此保留原始策略梯度期望。包含自己的组均值会把未归一化梯度缩为 $`(G-1)/G`$。

整条回答的 log-prob 是有效生成 token 的条件 log-prob 求和，REINFORCE 损失是负优势乘这个和。结果奖励 GRPO 常再除组标准差，改变不同问题权重，不等于同一个无偏目标；PPO 常用 Critic 和 GAE 估计前缀优势，信用分配更细。RLOO 没有独立 Critic，却仍有采样、评分和可能的参考模型成本。

RLOO 的留一基线本身不要求 clip；某些 Trainer 为复用同一 rollout，加入整序列新旧比率与裁剪，还把相对参考的 log-ratio 惩罚并入奖励。这是实现扩展，不能把未裁剪 on-policy 的无偏证明直接推广到多步裁剪更新，也不要重复算 KL。筛选 top-k、相关采样或跨题混组同样破坏原证明条件。$`G=1`$ 无定义，全组同分则优势全零；epsilon 无法解决这些信号问题。

```math
\begin{aligned}y_i&\overset{\mathrm{i.i.d.}}{\sim}\pi_{\mathrm{old}}(\cdot\mid x),\quad G\ge2,\quad\theta=\theta_{\mathrm{old}}\\b_i&=\frac1{G-1}\sum_{j\ne i}R_j,\quad A_i=R_i-b_i=\frac{G}{G-1}(R_i-\bar R)\\\mathcal L_{\mathrm{RF}}&=-\frac1G\sum_i\mathrm{sg}(A_i)\sum_{t\in\mathcal V_i}\log\pi_\theta(y_{i,t}\mid x,y_{i,\lt t})\\\mathbb E[(R_i-\bar R)\nabla_\theta\log\pi_\theta(y_i\mid x)]&=\frac{G-1}{G}\mathbb E[R_i\nabla_\theta\log\pi_\theta(y_i\mid x)]\quad\mathrm{(on\ policy)}\end{aligned}
```

#### 易错点

- 无偏证明依赖同题独立采样和未裁剪 on-policy 梯度，不能推广到任意多轮 Trainer。
- 留一均值不含自己，G=1 无定义，epsilon 不能补出基线。
- 完整回答优势不提供每个 token 的因果责任。

#### 追问

- RLOO的G=2优势与组均值中心化有何关系？
- 若只有top-k筛选后的回答参与更新，原来的无偏基线证明还成立吗？

### ALN-043 · 分类任务只用 SFT 是否够，GRPO 的收益与代价应怎样判断？

**L2** · 字节跳动

#### 答案

固定类别且标签可靠的分类任务，通常先做交叉熵或 SFT 基线；只有可验证推理、工具链或业务代价目标确实需要在线探索时，才评估 GRPO 是否值得。强化学习增加采样和奖励方差，不能因为能做就认为必须做。

公式中 $`\eta(c\mid x)`$ 是真实类别分布，$`p_\theta`$ 是模型分布。若模型能表示真实分布，交叉熵总体最优是匹配 eta，兼顾概率校准。采样正确性奖励的期望则是 $`\sum_c\eta(c\mid x)p_\theta(c\mid x)`$，无正则时偏向把概率集中到最可能类别。例如真实分布为 0.7、0.3，交叉熵鼓励预测 0.7、0.3，而采样正确率目标更偏向总选第一类。这个简化目标不是 argmax 准确率的可微公式，也不保证校准。

纯 0/1 类别奖励下，同题采样全对或全错，组内优势就为零；噪声标签和不平衡还会放大问题。先比较分类头、类别加权、阈值或受限标签解码。多 token 标签要看整段概率，不能只比较首 token，更要控制不同标签长度和无效格式。宏平均 F1 是数据集指标，不能未经设计直接当独立样本奖励。

公平实验固定数据划分、初始模型和推理预算，同时报告准确率、各类召回、macro-F1、拒答覆盖、log loss 或校准，以及延迟和训练成本。含图像时补充遮挡、替换或纯文本对照。若 GRPO 使用更长思考或更多候选，增益不能全归因算法；没有实际实验时应说明判断机制，不编造提升数字。

```math
\begin{aligned}\mathcal L_{\mathrm{CE}}&=\mathbb E_x\!\left[-\sum_c\eta(c\mid x)\log p_\theta(c\mid x)\right]\\ J_{\mathrm{correct}}&=\mathbb E_x\!\left[\sum_c\eta(c\mid x)p_\theta(c\mid x)\right]\end{aligned}
```

#### 易错点

- 固定标签分类不自动需要 RL，正确性奖励也不必然改善 macro-F1 或校准。
- 同组奖励全同则相对优势为零，但额外 KL 项可能仍有梯度。
- 标签长度、分词、无效输出和决策阈值都影响公平比较。

#### 追问

- 一组候选标签全部错误时，怎样判断需要改善初始化还是奖励？
- 类别不平衡时，accuracy提升而macro-F1下降应怎么排查？

### ALN-002 · 奖励模型如何用成对偏好训练？

**L2** · 阿里巴巴

#### 答案

成对偏好训练奖励模型，就是让它给同一问题的好回答打得比差回答高，从比较中学会评价质量。奖励模型通常读取问题和完整回答，输出一个标量分数；它的结构和大小不必与生成模型完全一致。

公式里 $`x`$ 是问题，$`y_w`$ 是优选回答，$`y_l`$ 是非优选回答，$`r_\phi`$ 是参数为 $`\phi`$ 的奖励模型，$`\sigma`$ 是 sigmoid。Bradley–Terry 假设用分数差的 sigmoid 表示优选概率。例如两个分数是 2 和 1，预测优选概率约为 0.73；如果顺序打反，损失会推动正确的分数差增大。这个建模假设便于训练，但现实偏好可能有平局、不传递和标注者差异，不能视为普遍规律。

成对标签约束的是相对次序，并不直接告诉质量差距。对同一问题所有回答同时加 10，分数差不变，因此绝对零点无法从比较唯一确定，应用时可能需要校准。数据要按领域、长度和标注者检查，防止模型学到“越长越好”。多个候选也不一定要做全部两两比较，可以通过排序或主动选择减少标注。

验收除了离线排序准确率，还要测当前策略新生成的回答。策略优化会寻找高分区域，可能放大评分漏洞；有限数据上高准确率不能保证整个生成空间都可靠。

```math
\mathcal{L}_{\mathrm{RM}}=-\mathbb{E}_{(x,y_w,y_l)}\left[\log\sigma\left(r_\phi(x,y_w)-r_\phi(x,y_l)\right)\right]
```

#### 易错点

- RM 高准确率不代表策略优化后分布外仍可靠。

#### 追问

- 如何处理平局与偏好不传递？

### ALN-015 · 如何识别和缓解 reward hacking，RM 业务判别准确率 100% 还会发生吗？

**L2** · 小红书 / 字节跳动 / 阶跃星辰 / 美团 / 快手 / 深势科技

#### 答案

Reward hacking 是模型越来越会拿高奖励，却没有更好地完成真实任务；即使奖励模型在一份业务测试集上判别全对，也仍可能发生。关键要区分“预测标签是否准确”和“分数是否代表完整真实效用”。

有限样本上分类或排序 100% 正确，只约束这些样本，不保证分数标定、类内排序和全部可生成回答都正确。比如两条回答都符合粗略合格标准，但空泛长文分数高于简洁正确答案，策略优化就可能不断加长。即使没有明显分布外变化，也可能利用这种类内分数缺陷。另一方面，业务规则只检查关键词、不检查事实或证据，本身就遗漏了真实需求；把奖励模型做大也不能补全没定义的目标。

但如果加强条件：在全部可达轨迹上，正确实现的奖励确实等于完整真实效用，任务与约束也一致，那么利用代理与真实目标不一致的投机按定义就被排除了，不能仍然断言必有 hacking。公式里的 $`u`$ 是真实效用，$`\hat r=au+b(x)`$、$`a>0`$，在固定问题分布下保留期望策略排序；仅有单调变换、分类全对或有限排序全对，没有同样保证。此时若训练变差，要检查优化失败、采样、其他损失或环境变化。

排查时保留轨迹和分项奖励，做长度、风格、事实的控制样本，对比训练评分器、独立评测和人工盲评。检查是否堆关键词、伪造工具结果或只学安全套话；多模态还要看画质、文字、动作与多样性。KL、早停和对抗反馈能缓解风险，但不能修好不完整规格，GRPO 的相对比较也不让奖励自动可靠。

```math
\begin{aligned}\mathrm{Acc}_{\mathcal D}(\hat r)&=1\ \not\Rightarrow\ \hat r(x,y)=u(x,y)\ \mathrm{on\ all\ reachable}\ (x,y)\\\hat r(x,y)&=a\,u(x,y)+b(x),\quad a\gt 0\\\mathbb E_{x\sim P,\,y\sim\pi}[\hat r]&=a\,\mathbb E[u]+\mathbb E_{x\sim P}[b(x)]\end{aligned}
```

#### 易错点

- 有限集分类全对，不证明连续奖励或业务评价规格完全正确。
- 如果所有可达轨迹的完整效用都被正确实现，就不能再用不存在的代理差距解释投机。
- 奖励投机、谄媚、模式坍缩与对齐税相关，但不是同义词。

#### 追问

- 保持业务数据分布不变，怎样构造分类仍全对但类内reward排序错误的控制例？
- 训练reward和人工质量分离后，怎样区分评分规格错误与RM泛化错误？

<a id="aln-016"></a>
### ALN-016 · 后训练为什么会出现对齐税或遗忘？

**L2**

#### 答案

后训练把模型的优化方向转向指令、偏好或安全要求，可能使部分原有能力下降，这类权衡常叫对齐税，旧任务明显退化也可能体现为遗忘。不是所有后训练都会损失能力，也不是所有分数下降都属于同一种问题。

例如模型变得更谨慎，合法问题却频繁拒答；或者偏好数据集中在中文聊天，代码和其他语言变差。要固定评测模板、解码参数、工具权限和预算，分别比较底座、SFT 和偏好训练阶段的任务表现。答案格式变化可能导致解析器误判，拒答倾向变化也可能掩盖原本知识，因此先排除测量问题，再讨论真正能力丢失。

缓解方法包括混入代表性通用或预训练数据、减小更新强度、正则约束和联合验证早停。比如在 PPO 中混合语言建模目标，可以给旧分布提供回放，但会占用新目标预算，也不保证保护所有能力。LoRA 或小学习率能限制变化，却无法证明没有遗忘。

Agent 中还要看任务成功率、过度拒绝合法工具、规划是否变保守以及额外调用成本。安全指标改善而某项效用下降，需要明确展示具体取舍；只有一个综合分数，会看不出究竟是知识遗忘、奖励偏差、格式变化还是执行策略改变。

#### 易错点

- LoRA 或小学习率可降低变化幅度，但不能保证没有遗忘。

#### 追问

- 如何区分知识丢失和评测 parser 失配？

<a id="aln-017"></a>
### ALN-017 · RLAIF 和 Constitutional AI 如何工作？

**L2**

#### 答案

RLAIF 用 AI 生成反馈或偏好来减少人工逐条标注，Constitutional AI 则用人定义的原则指导自我批评、修订和偏好训练。它们把人工工作更多转向制定规则与审计，而不是完全取消人工参与。

Constitutional AI 通常先让模型依据原则检查自己原来的回答，并生成修订答案，用这些数据做监督训练；再让 AI 比较候选，形成偏好数据，训练奖励或优化策略。比如原则要求尊重用户、避免无依据断言，模型可以据此指出原答复哪里有问题，再给出符合要求的版本。自我修订的 SFT 与 AI 成对偏好的强化学习，是不同信号和阶段。

原则可能冲突，裁判也可能事实错误、偏向某种措辞或过度拒答。如果同一个模型生成与评价，错误很容易相关，扩大数据量会把偏差反复传播。要保存原则、提示、裁判和数据版本，用专家、独立样本与可执行规则检查事实、长尾群体和合法请求的拒绝率。AI 反馈可降低成本，但不能把“裁判喜欢”直接等同于“真实需求被满足”。

#### 易错点

- 模型反馈可能传播同类错误，数据量增加不能替代质量核验。

#### 追问

- 同一个模型生成和打分会产生哪些相关误差？

<a id="aln-020"></a>
### ALN-020 · 多目标奖励发生冲突时如何处理？

**L3** · 深势科技

#### 答案

多目标奖励冲突时，先明确哪些要求必须满足，哪些质量可以交换，再决定约束、优先级或加权方式。正确性、简洁、有用和安全常不能同时无限提高，用一个总分相加并不会自动解决冲突。

例如一个答案很短但遗漏关键条件，另一个正确却稍长，应让内容质量与长度权衡；严重违规则可能需要硬约束，而不是靠多一点“有用分”抵消。加权前要校准各分项量纲和方差，如果正确性是 0 到 1，长度惩罚却随 token 增到上百，后者可能无意主导训练。可以先用简洁正确、冗长正确、错误套话和空答案等控制样本，检查分项方向与尺度。

对可交换目标，可以比较 Pareto 前沿，也就是某项改善必须牺牲另一项的候选方案；对硬要求，可用门控或约束优化，并单独验收是否达标。保留分项奖励和分层失败案例，检查模型是否通过空回答或过度拒绝绕开风险。更多奖励项也会引入更多漏洞，不能保证每项单调改善。最终选择应按业务成本和明确优先级，而不是只挑训练综合分最高的模型。

#### 易错点

- 奖励简单相加不保证满足硬约束，也不保证各项单调改善。

#### 追问

- 如何确定安全阈值并防止模型输出空答案拿高分？

<a id="aln-033"></a>
### ALN-033 · 提升 RAG 回答质量时怎样选 DPO 或 GRPO，奖励怎样设计？

**L3**

#### 答案

提升 RAG 回答质量，先判断错误在检索还是回答，再决定用 DPO 或 GRPO；两种训练都不能替代缺失证据的检索。已有同问题、同证据的可靠偏好对，DPO 较直接；能在线多次生成并可信评分，则可以比较 GRPO 的探索收益。

DPO 数据要控制输入条件。例如优选答案拿到正确文档，非优选却没拿到，模型学到的可能是证据差异，不是怎样更好回答。最好在相同证据下比较正确性、忠实引用和需求满足。GRPO 可对同输入采多条候选，分别检查答案是否正确、结论是否被证据支持、引用是否真实有效，以及是否遵守约束。

不要只奖励引用数量、格式或参考答案词面重合。模型可能堆无关引用，或用看似有依据的措辞掩盖不支持的结论；开放问答的 AI 裁判也需要独立核验。组内相对优势并不会把错误奖励变成可靠监督。没有证据时的适当拒答也要明确，不应靠空答案一律得高分。

实验先固定索引、检索器、提示和推理预算，比较 SFT、DPO 与 GRPO，再分别测相同检索条件下的回答质量和端到端表现。记录召回、证据忠实、拒答、成本和分布外泛化，区分模型真正更会使用证据，还是更会迎合引用评分器。

#### 易错点

- RAG不是天然必须用DPO；GRPO也不因组内比较就免于奖励作弊。

#### 追问

- 怎样区分策略更会回答与它只是更会迎合引用评分器？
